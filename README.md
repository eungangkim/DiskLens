# DiskLens

Windows C드라이브의 용량을 폴더/파일별로 보여 주고, 각 항목이 **무엇인지**와 **지워도 되는지(안전도)**를 알려 주며, 임시파일·캐시 정리와 프로그램 제거까지 한 화면에서 처리하는 데스크탑 앱입니다. 모든 판단은 앱에 들어 있는 규칙 파일로만 하며, **인터넷에 연결하지 않습니다.**

## 후원

DiskLens가 도움이 되었다면 [커피 한 잔으로 응원](https://buymeacoffee.com/kimeungang)해 주세요. 후원은 선택 사항이며, 앱의 기능은 모두 무료입니다.

## 설치

`npm run dist`로 `release` 폴더에 두 가지 파일이 만들어집니다.

| 파일                          | 설명                                                                                |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| `DiskLens-Setup-x.y.z.exe`    | 설치 프로그램. 관리자 권한 없이 내 계정에만 설치되고, 설치 폴더를 고를 수 있습니다. |
| `DiskLens-Portable-x.y.z.exe` | 설치 없이 바로 실행하는 포터블 버전.                                                |

### Windows SmartScreen / 백신 경고

이 앱은 **코드 서명이 되어 있지 않습니다.** 그래서 처음 실행할 때 "Windows의 PC 보호" 창(SmartScreen)이 나타날 수 있습니다. 이때 **추가 정보 → 실행**을 누르면 됩니다. 일부 백신(예: Avast)은 서명 없는 새 프로그램의 실행을 막거나 검사에 시간이 걸릴 수 있습니다. 직접 만든 파일이라면 백신의 예외 목록에 추가하세요. 이 앱은 어떤 네트워크 통신도 하지 않습니다.

## 사용법

1. **스캔** — [스캔 시작]을 누르면 C드라이브를 읽어 폴더별 용량을 보여 줍니다(파일을 바꾸거나 지우지 않습니다). 다음에 열면 마지막 결과가 먼저 나옵니다.
2. 항목을 선택하면 오른쪽에 **이게 뭔지, 지우면 어떻게 되는지, 안전도**가 나옵니다. 🟢 안전 / 🟡 주의 / 🔴 보호 / ⚪ 알 수 없음.
3. **정리** — 임시파일·캐시 항목을 분석(미리보기)하고, 체크한 뒤 확인 창에서 실행합니다. 기본은 **휴지통으로 이동**입니다(휴지통을 비워야 용량이 늘어납니다).
4. **프로그램** — 설치된 프로그램을 크기순으로 보고, [제거]로 그 프로그램의 **공식 제거 프로그램**을 실행합니다.
5. **기록** — 지난 정리의 날짜, 확보 용량, 항목별 결과. **설정** — 단위(GiB/GB), 테마, 제외 폴더, 영구 삭제 허용 등.

## 안전 정책 요약

- 보호 경로(Windows 시스템 폴더, 사용자 문서 등)는 규칙과 관계없이 **절대 삭제하지 않습니다.** 규칙에 없는 항목(⚪ 알 수 없음)도 삭제할 수 없습니다.
- 삭제는 항상 미리보기와 **확인 창**을 거치며, 기본은 휴지통 이동입니다. 영구 삭제는 설정에서 허용했을 때 임시·캐시 항목에만 가능합니다.
- 관리자 권한은 평소에 쓰지 않습니다. `C:\Windows\Temp` 같은 일부 항목만 실행할 때 Windows 권한 확인 창(UAC)을 띄우고, 거부하면 그 항목만 건너뜁니다. 관리자 헬퍼는 임의 경로가 아니라 **정해진 규칙 ID만** 받습니다.
- 프로그램 제거는 그 프로그램의 공식 제거 프로그램만 실행합니다. 폴더·레지스트리를 앱이 직접 지우지 않으며, 레지스트리는 읽기만 합니다.
- 모든 삭제/제거 작업은 사용자 데이터 폴더의 로그에 기록됩니다.

사용자 데이터 위치: `%APPDATA%\disklens` (설정, 스캔 캐시, 정리 기록, `logs` 폴더, 직접 추가한 `user-rules.json`). 설정 화면에서 폴더를 바로 열 수 있습니다. 앱을 제거할 때 이 데이터를 함께 지울지 묻습니다(기본: 남김).

## 알려진 한계

- Windows 10/11 x64 전용, C드라이브 기준입니다.
- OneDrive 등 "온라인 전용" 파일은 따로 구분하지 않습니다.
- 사용자 규칙 파일(`user-rules.json`)은 앱을 다시 시작해야 반영됩니다. 폴더에 사용자 메모를 남기는 기능은 없습니다.
- 코드 서명이 없어 SmartScreen 경고가 뜹니다. 제거 프로그램이 스스로 다시 실행되는 경우 앱이 완료를 일찍 보고할 수 있습니다(목록을 새로 고치면 확인됩니다).

## 개발

```bash
npm install
npm run dev          # 개발 모드
npm run typecheck && npm run lint && npm test
npm run test:e2e     # 화면 테스트 (가짜 C 드라이브에서만 실행)
npm run dist         # 설치 파일 + 포터블 생성 (release 폴더)
```

문서는 `docs/`, 작업 규칙은 `CLAUDE.md`를 보세요. 규칙 파일은 `resources/cleanup-rules.json`입니다.
