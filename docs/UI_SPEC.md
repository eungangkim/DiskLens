# UI_SPEC — 화면 명세

앱 언어: 한국어. 창 기본 크기 1280×800, 최소 1000×650. 라이트/다크 테마 지원.
디자인 원칙: **"무엇이 큰지 → 이게 뭔지 → 지워도 되는지"가 한 시선 흐름으로** 보이게 한다. 장식보다 정보 가독성 우선.

## 1. 전체 레이아웃

```
┌────────────────────────────────────────────────────────────────────┐
│ [로고] DiskLens                         C: 931GB 중 812GB 사용 (87%) │ ← 상단바(드라이브 용량 막대)
├──────────┬─────────────────────────────────────────────────────────┤
│ 사이드바  │                                                         │
│  📊 스캔  │                    메인 영역                             │
│  🧹 정리  │                (탭별 화면)                               │
│  📦 프로그램│                                                         │
│  📜 기록  │                                                         │
│  ⚙ 설정  │                                                         │
└──────────┴─────────────────────────────────────────────────────────┘
```

- 사이드바 5개 메뉴: 스캔 / 정리 / 프로그램 / 기록(P1) / 설정.
- 상단바: 드라이브 사용량 막대 (총/사용/여유). 정리 후 갱신.
- 전역 하단 상태바: 진행 중 작업(스캔/정리) 표시 + 취소 버튼.

## 2. 공통 컴포넌트

### 2.1 안전도 배지

| 값        | 색(라이트 기준) | 아이콘    | 텍스트     |
| --------- | --------------- | --------- | ---------- |
| safe      | 초록            | ✔ 원      | 안전       |
| caution   | 노랑/주황       | ⚠ 삼각    | 주의       |
| protected | 빨강            | 🔒 자물쇠 | 보호       |
| unknown   | 회색            | ? 원      | 알 수 없음 |

- 항상 **아이콘 + 텍스트 + 색**을 함께 사용. 호버 시 한 줄 요약 툴팁.
- 다크 모드에서 명도 대비(WCAG AA) 확보.

### 2.2 용량 표시

- 설정의 단위(GiB/GB)에 맞춰 자동 단위(B/KB/MB/GB/TB). 소수점 1자리.
- 비율 막대: 부모 대비 비율(가로 막대) + 숫자(%).

### 2.3 확인 대화상자 (삭제/제거 공통)

- SAFETY.md §9 요구사항 충족: 항목 수, 총 용량, 방식, 큰 항목 3개, 경고 문구.
- 영구 삭제: 빨간 강조 + 체크박스 "되돌릴 수 없음을 이해했습니다" 체크 전에는 실행 버튼 비활성.
- 기본 포커스: 취소.

### 2.4 빈 상태/오류 상태

- 스캔 전: "아직 스캔한 기록이 없습니다. [C: 드라이브 스캔 시작]" 큰 버튼.
- 오류: 토스트(일시적) + 상세는 "자세히" 펼침. 권한 오류는 오류가 아니라 "건너뜀 N개"로 표시.

## 3. 화면: 스캔 (메인 화면)

### 3.1 상단 영역

- [스캔 시작/다시 스캔] 버튼, 스캔 루트 표시(기본 C:\), "마지막 스캔: 2026-11-01 14:03 (캐시)" 표시.
- 스캔 중: 진행 패널 — 스캔한 파일 수, 누적 용량, 경과 시간, 현재 경로(말줄임), **[취소]** 버튼. 진행 막대(전체 사용량 대비 추정치).
- 건너뜀 표시: "접근 불가 N개 [보기]" → 목록 모달.

### 3.2 뷰 전환 탭 (스캔 결과 상단)

1. **폴더 트리** (기본)
2. **큰 파일 Top** (상위 100~500)
3. **큰 폴더 Top**
4. **유형별 요약**

### 3.3 폴더 트리 뷰

테이블형 트리(가상 스크롤). 컬럼:

| 컬럼    | 내용                                                                    |
| ------- | ----------------------------------------------------------------------- |
| 이름    | 펼침 화살표 + 폴더/파일 아이콘 + 이름                                   |
| 크기    | 용량 (내림차순 기본 정렬)                                               |
| 비율    | 부모 대비 가로 막대 + %                                                 |
| 파일 수 | 하위 전체                                                               |
| 안전도  | 배지                                                                    |
| 설명    | 규칙 이름 한 줄 (예: "Chrome 캐시") / 없으면 프로그램 힌트 / 없으면 "—" |

- 행 클릭: 선택 → **우측 상세 패널** 갱신. 더블클릭/화살표: 펼치기(지연 로딩, `scan:getChildren`).
- 같은 레벨의 작은 폴더들은 "기타 N개 (용량)" 행으로 접혀 표시.
- 링크/정션은 링크 아이콘 + "(링크, 집계 제외)".
- 클라우드 전용 파일은 구름 아이콘.
- 상단 필터 바: **안전도 필터**(전체/안전/주의/보호/알 수 없음), **"지워도 되는 것만 큰 순으로"** 토글(→ 안전 + 정리 가능 항목을 큰 순 평면 목록으로 표시), 이름 검색.
- 키보드: ↑↓ 이동, →← 펼치기/접기, Enter 상세, Delete는 **동작 없음**(삭제는 버튼과 확인 대화상자로만).

### 3.4 우측 상세 패널 (선택 항목)

```
이름: Chrome 캐시                     [🟢 안전]
경로: C:\Users\...\Chrome\User Data\Default\Cache   [탐색기에서 열기] [경로 복사]
크기: 4.2 GiB (전체의 0.5%)  파일 3,214개

■ 이게 뭔가요?
 브라우저가 웹페이지를 빠르게 불러오려고 저장해 둔 임시 데이터입니다.

■ 지우면?
 처음 방문하는 사이트가 잠시 느려질 수 있습니다. 로그인은 유지됩니다.

카테고리: 캐시   |   규칙: chrome-cache (내장)

[ 이 항목 정리하기 ]   ← safe/caution + cleanable일 때만 표시. 클릭 시 정리 계획 → 확인 흐름
```

- "이 항목 정리하기"는 선택한 폴더 하나가 아니라 **그 폴더에 매칭된 규칙 전체**(예: 모든 Chrome 프로필의 Cache)를 정리 항목 단위로 처리한다. 확인 대화상자에 대상 경로를 모두 보여준다.
- `protected`: 버튼 대신 "🔒 시스템/프로그램에 필요한 항목이라 삭제할 수 없습니다" + 줄이는 방법 안내(규칙의 impact 문구).
- `unknown`: "알 수 없는 항목입니다. 탐색기에서 확인해 보세요." + 프로그램 힌트(있으면) + [탐색기에서 열기]. 삭제 버튼 없음.
- 프로그램 폴더면: "프로그램 'X'(게시자 Y)의 설치 폴더입니다" + **[프로그램 탭에서 보기]** 링크 (삭제는 프로그램 제거로).

### 3.5 큰 파일 Top 뷰

- 컬럼: 파일명, 경로(말줄임+툴팁), 크기, 수정일, 확장자, 안전도(해당 규칙 있을 때만, 대부분 unknown).
- 파일은 직접 삭제 버튼을 제공하지 않는다 (이번 범위: `unknown` 파일 삭제 불가). [탐색기에서 열기]만. → 사용자가 직접 탐색기에서 판단.

### 3.6 유형별 요약 뷰

- 막대 차트(가로): 영상/이미지/압축/실행파일/문서/코드/디스크 이미지/기타 → 용량, 파일 수.

## 4. 화면: 정리

### 4.1 구성

- 상단 요약: "정리 가능한 항목 N개, 예상 확보 약 XX GiB (분석 후)".
- 버튼: **[분석하기]**(미리보기, 삭제 없음), **[안전 항목만 선택]**, **[선택 항목 정리]**(분석 완료 후 활성).
- 본문: 그룹(Windows / 브라우저 / 개발 도구 / 게임·앱 / 기타)별 접이식 리스트.

### 4.2 항목 행

`[체크박스] 이름 | 안전도 배지 | 설명 한 줄 | 예상 용량 | [관리자 필요] 배지 | [실행 중 프로세스 경고]`

- 체크박스 기본값: 규칙의 `defaultSelected` (safe만).
- `caution` 항목은 체크 시 행 아래에 경고 문구(impact)가 펼쳐지고, 실행 시 확인 대화상자에서 별도 동의 체크 필요.
- 항목 클릭 시 상세(대상 경로 샘플 3개, 설명, 영향).
- 분석 전에는 용량 "—", 분석 중에는 스피너, 분석 후 숫자 + 파일 수.

### 4.3 흐름

1. [분석하기] → 항목별 용량 계산(삭제 없음), 진행 표시.
2. 사용자가 체크 선택 (또는 [안전 항목만 선택]).
3. [선택 항목 정리] → 확인 대화상자(SAFETY.md §9) → 삭제 방식 표시(기본 "휴지통으로 이동", 설정에서 영구 삭제가 허용되고 `allowPermanent` 항목에 한해 "영구 삭제" 라디오 선택 가능).
4. 실행: 진행 패널(항목별 진행, 확보한 용량 실시간), **[취소]**.
5. 결과 화면: "확보한 용량 X GiB / 삭제 N개 / 건너뜀 M개". 건너뜀 사유별 집계(사용 중, 권한, 관리자 거부). [정리 기록에 저장됨] 안내. [다시 스캔하기] 제안.

- (8단계 현재) 관리자 필요 항목은 "관리자 필요" 배지를 보이고, 실행하면 Windows 권한 확인 창(UAC)이 한 번 나타난다. 거부하면 그 항목들만 "관리자 권한을 허용하지 않아 건너뜀"으로 집계된다. 관리자 항목은 처음부터 체크하지 않고 [안전 항목만 선택]/[원클릭]에도 포함하지 않는다(직접 체크할 때만). 특수 동작 항목(휴지통 비우기·Windows.old 등)은 "다음 단계에서 지원"으로 선택할 수 없다.
- 관리자 필요 항목이 있으면 확인 대화상자에 "일부 항목은 관리자 권한이 필요합니다. 계속하면 Windows 권한 확인 창이 나타납니다" 안내.
- `휴지통 비우기`, `Windows 디스크 정리 실행` 같은 specialAction 항목은 별도 설명과 함께 표시.

### 4.4 원클릭 안전 정리

- 정리 화면 상단 큰 버튼 **[원클릭 안전 정리]** = (분석 → `safe` 항목 자동 선택 → 확인 대화상자). 확인 단계는 생략하지 않는다. `caution`은 포함되지 않는다.

## 5. 화면: 프로그램

### 5.1 목록

컬럼: 이름 | 게시자 | 크기 | 버전 | 설치일 | 안전도(제거 영향) | [제거]

- 정렬: 크기순(기본)/이름/설치일. 검색창. 토글: "시스템 구성요소 표시"(기본 꺼짐).
- 크기가 레지스트리에 없는 프로그램은 설치 폴더 스캔 결과(있으면)로 보완하고, 없으면 "—".
- 안전도 의미(프로그램): safe/unknown → "제거 가능", caution → "다른 프로그램이 필요로 할 수 있음", protected → "제거 불가".

### 5.2 행 선택 → 상세

- 설치 경로, 게시자, 규칙 설명(있으면), [설치 폴더 열기], [설치 폴더를 스캔 결과에서 보기](스캔 탭의 해당 노드로 이동).

### 5.3 제거 흐름

- [제거] → 확인 대화상자(이름, 게시자, 버전, 용량, 실행할 제거 프로그램 이름, caution이면 경고 + "읽었고 이해했습니다" 체크 전에는 실행 불가) → 공식 제거 프로그램 실행. 기본 포커스는 [취소], Esc 로 취소. 앱이 폴더·레지스트리를 직접 지우지 않으며 UAC 가 나타날 수 있다고 안내.
- protected 는 [제거] 비활성(툴팁에 이유), 제거 명령이 없거나 안전하지 않은 형식이면 역시 비활성. 제거가 진행 중이면 모든 [제거]가 비활성.
- 실행 중: "제거 프로그램이 실행되었습니다. 완료될 때까지 기다리는 중…" (제거 창은 해당 프로그램이 띄움).
- 완료 후 목록 자동 새로고침 + "남은 폴더 후보" 알림(있으면, P1): 설치 폴더가 아직 존재하면 "남은 폴더가 있습니다 [보기]" → 스캔 탭에서 해당 폴더 열기(삭제는 SAFETY.md 규칙에 따라 가능한 경우에만).
- 제거 프로그램 실행 실패 시 오류 메시지(원인) 표시.

## 6. 화면: 기록 (P1)

- 정리/제거 기록 목록: 날짜, 종류, 확보 용량, 항목 요약. 행 클릭 → 상세(항목별 결과, 건너뜀 사유).
- [로그 폴더 열기] 버튼.

## 7. 화면: 설정

- 스캔 루트 (기본 C:\, 폴더 선택 다이얼로그)
- 제외 폴더 목록 (추가/삭제)
- 용량 단위: GiB(1024 기준) / GB(1000 기준)
- 디스크 점유 크기 기준으로 계산 (켜짐 기본)
- 삭제 방식: "항상 휴지통" (기본) / "임시·캐시 항목에 한해 영구 삭제 허용" (경고 문구 포함, 기본 꺼짐)
- 사용자 규칙 파일 경로 / [규칙 다시 불러오기] / 규칙 버전 표시
- 테마
- 앱 정보: 버전, 규칙 버전, 로그 폴더 열기, 사용자 데이터 폴더 열기
- 안내: "이 앱은 인터넷에 연결하지 않습니다."

## 8. 상호작용·접근성·성능 요구

- 모든 인터랙티브 요소는 키보드로 접근 가능, 포커스 표시.
- 가상 스크롤: 한 번에 보이는 행만 렌더. 폴더 하위는 펼칠 때 로드.
- 스캔/정리 중에도 다른 탭 이동 가능(작업은 전역 상태바에서 계속 표시).
- 스캔 진행 중에는 결과를 점진적으로 보여주지 않아도 되지만(P2), 최종 완료 직후 즉시 상위 폴더가 용량순으로 나와야 한다.
- 긴 경로: 중간 말줄임 + 툴팁 + 복사 버튼.
- 모든 문구는 한국어, 전문 용어는 풀어서 (예: "정션" → "링크 폴더").

## 9. 문구 톤 가이드

- 쉬운 말, 짧게. 불안을 주기보다 판단 근거를 준다.
- 위험 문구는 구체적으로: "삭제하면 Chrome에서 다시 로그인해야 할 수 있습니다" (O) / "위험할 수 있습니다" (X).
- 삭제 버튼 라벨은 동작을 정확히: "휴지통으로 이동", "영구 삭제".
