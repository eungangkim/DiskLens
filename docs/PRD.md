# PRD — 제품 요구사항 문서

## 1. 배경과 목적

C드라이브(1TB)가 점점 부족해지는데, 무엇이 용량을 차지하는지 확인하고, 각 항목이 무엇인지 검색하고, 지워도 되는지 판단하는 과정이 번거롭다.
이 앱은 **"용량 + 용도 설명 + 삭제 안전도"를 한 화면에서** 보여주고, 안전한 정리는 바로 실행할 수 있게 한다.

기존 도구(WizTree, TreeSize 등)는 용량은 잘 보여주지만 "이게 뭔지/지워도 되는지"는 알려주지 않는다. 이 앱의 차별점은 **용도 설명과 안전도 표시**다.

## 2. 사용자

- 1인 사용자(개발자 본인). Windows PC 사용. 개발 도구(Node, Unity, Docker/WSL 등)와 게임을 사용해 캐시/빌드 산출물이 많다.
- 컴퓨터 시스템에 대한 지식이 깊지 않아도 "지워도 되나?"를 판단할 수 있어야 한다.

## 3. 범위

### 포함

1. 용량 스캔
2. 용도 설명
3. 제거 안전도 표시
4. 설치 프로그램 목록 및 제거
5. 임시파일/캐시 자동정리
6. UI (데스크탑 앱), 설치 파일 배포

### 제외 (이번 버전에서 하지 않음)

- Claude API 등 AI 연동 (용도 설명은 규칙 DB만)
- C드라이브 외 드라이브 지원 (구조는 확장 가능하게 하되 UI/테스트는 C: 기준)
- 중복 파일 탐지, 개인 문서/사진 분석
- 프로그램 강제 삭제, 레지스트리 정리
- 클라우드 동기화, 자동 업데이트, 계정/로그인
- macOS/Linux 지원

## 4. 기능 요구사항

우선순위: P0(필수) / P1(중요) / P2(여유 시)

### F1. 용량 스캔 (P0)

- 지정한 루트(기본 `C:\`)를 스캔하여 폴더별/파일별 용량을 집계한다.
- 폴더 용량 = 하위 모든 파일의 합. 용량 내림차순 정렬 기본.
- 스캔 중 진행 상태(스캔한 파일 수, 누적 용량, 현재 경로)를 실시간 표시하고, **취소** 가능.
- 접근 불가(권한) 폴더는 건너뛰고 "건너뛴 항목 N개"로 집계하여 목록으로 볼 수 있다.
- 심볼릭 링크/정션은 따라가지 않는다. OneDrive 등 클라우드 플레이스홀더 파일(온라인 전용)은 디스크 점유 0으로 취급하거나 별도 표시한다.
- `hiberfil.sys`, `pagefile.sys`, `swapfile.sys` 등 시스템 파일은 목록에 포함하되 용도 설명을 붙인다.
- 스캔 결과는 디스크에 캐시한다. 다음 실행 시 캐시를 먼저 보여주고(“마지막 스캔: 날짜”), 사용자가 "다시 스캔"으로 갱신한다.
- 결과 화면: 폴더 트리(펼치기/접기), 용량, 전체 대비 비율 막대, 파일 수.
- 상위 N개 큰 파일 / 큰 폴더 보기 (기본 100개).
- 확장자/파일 유형별 용량 요약 (영상, 이미지, 압축파일, 실행파일, 기타).
- 선택 항목에서 "탐색기에서 열기".

**완료 조건**

- 일반 권한으로 `C:\` 스캔이 끝까지 완료되고, 중간 취소 시 1초 내 중단된다.
- 스캔 중 UI가 멈추지 않는다(60fps 아니어도 입력 반응 지연 없음).
- 같은 폴더의 용량이 탐색기 속성 값과 큰 차이 없다 (권한 오류로 건너뛴 부분 제외, 오차 사유는 UI에 표시).
- 정션/심볼릭 링크 이중 집계가 없다.

### F2. 용도 설명 (P0)

- 스캔 결과의 각 폴더/파일에 대해 **규칙 DB**를 매칭하여 설명을 표시한다.
- 설명에는 다음이 포함된다: 이름(예: "Windows 임시 폴더"), 무엇인지 1~2문장, 지우면 생기는 영향, 카테고리.
- 규칙이 없는 항목은 "알 수 없음" + 상위 경로/설치 프로그램 정보로 힌트를 준다 (예: `Program Files\X` 하위면 "프로그램 X의 설치 폴더일 가능성").
- 설치 프로그램 목록과 폴더를 연결한다: 레지스트리의 `InstallLocation`, 이름 유사도로 매칭하여 "이 폴더는 [프로그램명] (게시자 ...)의 설치 폴더" 표시.
- 규칙 DB는 앱에 내장된 JSON(`resources/cleanup-rules.json`)이며, 사용자가 **자신의 규칙 파일(`user-rules.json`)을 추가**할 수 있다 (P1).
- 사용자가 "알 수 없음" 항목에 직접 메모를 남길 수 있다 (P2).

**완료 조건**

- 시드 규칙에 있는 대표 경로(Temp, 브라우저 캐시, Windows.old, node_modules, Unity Library 등)가 올바른 설명으로 표시된다.
- 규칙 매칭이 가장 구체적인(더 긴/정확한) 규칙을 우선한다.
- 환경변수 경로가 실제 사용자 경로로 확장되어 매칭된다.

### F3. 제거 안전도 표시 (P0)

- 모든 항목에 4단계 중 하나를 표시한다 (정의는 SAFETY.md).
  - 🟢 `safe` 안전: 지워도 시스템/프로그램에 문제 없음 (필요 시 자동 재생성)
  - 🟡 `caution` 주의: 지울 수 있으나 영향이 있음 (다시 받아야 함, 설정 손실 등)
  - 🔴 `protected` 보호: 건드리면 안 됨. 삭제/정리 버튼 비활성
  - ⚪ `unknown` 알 수 없음: 규칙 없음. 삭제 버튼은 "탐색기에서 열기"만 제공 (삭제 불가)
- 색상 + 아이콘 + 텍스트 라벨로 표시 (색맹 고려, 색만으로 구분하지 않음).
- 폴더의 안전도는 규칙이 있으면 규칙을, 없으면 `unknown`. 하위에 `protected`가 섞여 있는 폴더를 통째로 삭제하는 것은 불가 (SAFETY.md).
- 필터: 안전도별로 목록 필터링, "지워도 되는 것만 큰 순으로" 보기.

**완료 조건**

- 모든 목록 행에 안전도 배지가 보인다.
- `protected`/`unknown` 항목에서 삭제 관련 버튼이 비활성이거나 없다.
- "안전한 것만 보기" 필터 시 `safe`만 용량 순으로 나온다.

### F4. 설치 프로그램 목록 및 제거 (P0)

- 레지스트리(`HKLM\...\Uninstall`, `HKLM\WOW6432Node\...\Uninstall`, `HKCU\...\Uninstall`)에서 설치된 프로그램 목록을 읽는다 (읽기 전용).
- 표시 항목: 이름, 게시자, 버전, 설치일, 추정 용량(레지스트리 `EstimatedSize` 또는 설치 폴더 스캔 결과), 설치 경로.
- 정렬/검색/필터(용량순, 이름순, 최근 설치순).
- **제거**: 선택한 프로그램의 `UninstallString`(또는 `QuietUninstallString`)을 실행하여 해당 프로그램의 공식 제거 프로그램을 띄운다. 앱은 제거 프로그램의 완료를 기다리고, 끝나면 목록을 새로고침한다.
- 제거 전 확인 대화상자: 프로그램명, 게시자, 용량 표시.
- 시스템 구성요소/보호 프로그램(예: Microsoft Visual C++ 재배포 패키지, GPU 드라이버, .NET 런타임 등)은 제거 시 경고(주의) 또는 비활성(보호)로 표시한다. 목록은 규칙 DB의 프로그램 규칙을 따른다.
- 강제 삭제, 남은 파일/레지스트리 찌꺼기 자동 삭제는 하지 않는다. 대신 제거 후 "남은 폴더 후보"를 보여주고, 사용자가 SAFETY.md 규칙 하에 정리할 수 있게 한다 (P1).

**완료 조건**

- 설정 → 앱 목록과 동일한 프로그램이 (시스템 컴포넌트 포함 여부는 토글) 표시된다.
- 제거 버튼이 공식 제거 프로그램을 실행한다 (테스트는 모의 제거 프로그램으로).
- 제거 프로그램 실행에 실패해도 앱이 죽지 않고 오류 메시지를 보여준다.

### F5. 임시파일/캐시 자동정리 (P0)

- 규칙 DB의 `cleanable: true` 규칙들을 "정리 항목"으로 묶어 보여준다. 항목별로: 이름, 설명, 현재 용량, 예상 확보 용량, 안전도, 체크박스.
- 기본 정리 항목 예시: 사용자/Windows 임시 폴더, Windows 업데이트 다운로드 캐시, 썸네일 캐시, 브라우저 캐시(Chrome/Edge/Firefox 등), 휴지통, 크래시 덤프/로그, npm/pip/gradle/NuGet 캐시, GPU 셰이더 캐시 등.
- 플로우: **분석(미리보기) → 선택 → 확인 → 실행 → 결과 리포트**.
  - 분석: 실제 삭제 없이 대상 파일 수와 용량 계산.
  - 실행: 선택한 항목만. 사용 중이라 못 지운 파일은 건너뛰고 집계.
  - 결과: 확보한 용량, 건너뛴 파일 수와 사유.
- 삭제 방식은 SAFETY.md를 따른다 (기본 휴지통, 임시/캐시 카테고리만 영구 삭제 선택 가능).
- "원클릭 안전 정리": `safe` 항목만 자동 선택해서 분석 → 확인 → 실행. (확인 단계는 생략하지 않는다.)
- 관리자 권한이 필요한 항목(예: `C:\Windows\Temp`, `SoftwareDistribution\Download`)은 "관리자 권한 필요" 배지를 달고, 실행 시 UAC 상승을 요청한다. 거부하면 해당 항목만 건너뛴다.
- 정리 기록(날짜, 확보 용량, 항목)을 로컬에 저장하고 "정리 기록" 화면에서 볼 수 있다 (P1).
- 예약 자동 실행(주기적 정리)은 P2. 구현 시에도 `safe` 항목만, 실행 전 알림 필요.

**완료 조건**

- 미리보기와 실제 실행 결과 용량이 대체로 일치한다.
- 실행 중 취소 가능하다.
- 사용 중 파일/권한 오류가 있어도 중단되지 않고 결과 리포트에 기록된다.
- 정리 대상이 아닌 경로(`protected`, `unknown`)는 어떤 경로로도 삭제되지 않는다 (테스트로 검증).

### F6. 설정 (P1)

- 스캔 대상 루트 선택, 제외 폴더 지정.
- 용량 단위 표시(GB/GiB).
- 삭제 방식 옵션: 기본 "휴지통", 임시/캐시에 한해 "영구 삭제" 허용 토글(기본 꺼짐).
- 사용자 규칙 파일 경로.
- 테마(라이트/다크/시스템).

### F7. 설치 및 배포 (P0)

- `npm run dist` 한 번으로 NSIS 설치 파일(.exe)과 포터블 실행 파일이 생성된다.
- 설치 파일은 사용자 단위 설치(관리자 불필요) 기본, 바탕화면/시작 메뉴 바로가기 생성 옵션.
- 앱 버전/아이콘/이름 설정. 제거(언인스톨) 시 사용자 데이터(스캔 캐시, 설정) 삭제 여부를 묻는다.
- 코드 서명이 없으면 SmartScreen 경고가 뜬다는 점을 README에 안내한다 (서명은 이번 범위 밖, 추후 선택).

## 5. 비기능 요구사항

| 항목     | 기준                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 성능     | 1TB/수백만 파일 기준 일반 권한 풀 스캔이 수 분 내 완료(목표 5분 이내, 하드웨어 의존). 스캔 중 UI 지연 없음 |
| 메모리   | 스캔 중 앱 메모리 1.5GB 이하 목표. 파일 단위 전체 보관 금지, 폴더 단위 집계                                |
| 안전성   | 어떤 버그가 있어도 보호 경로가 삭제되지 않도록 방어 계층 2중 이상 (SAFETY.md)                              |
| 오프라인 | 네트워크 없이 모든 기능 동작. 외부 통신 없음                                                               |
| 보안     | contextIsolation, sandbox, CSP 설정. renderer에서 임의 경로 삭제 요청 시 main에서 재검증                   |
| 접근성   | 키보드 조작, 색상 외 아이콘/텍스트로 안전도 구분                                                           |
| 로그     | 삭제/제거 작업은 로컬 로그 파일에 항상 기록 (시간, 경로, 결과)                                             |
| 한국어   | UI 기본 언어 한국어                                                                                        |

## 6. 성공 지표 (개인용 기준)

- 첫 스캔 후 10분 안에 "지워도 되는 용량 상위 항목"을 파악할 수 있다.
- 사용자가 개별 항목 속성을 눌러보거나 검색하는 일이 크게 줄어든다.
- 안전 정리 1회 실행으로 눈에 띄는 용량(수 GB 이상)을 확보한다.
- 정리 후 시스템/프로그램 오작동 0건.

## 7. 가정과 위험

| 위험                              | 대응                                                                  |
| --------------------------------- | --------------------------------------------------------------------- |
| 규칙 DB가 부족해 `unknown`이 많음 | 시드 규칙을 충분히 만들고, 사용자 규칙/메모(P2)로 확장 가능하게 설계  |
| 잘못된 규칙으로 중요한 파일 삭제  | 보호 경로 하드코딩(규칙과 독립), 휴지통 우선, 미리보기와 확인 필수    |
| 스캔이 느림                       | worker 병렬화, 결과 캐시, 후순위로 WizTree CSV 가져오기/네이티브 모듈 |
| 관리자 권한 필요 영역             | 권한 상승은 필요한 정리 항목에 한정, 거부 시 건너뛰기                 |
| 코드 서명 없음(SmartScreen 경고)  | README 안내. 필요 시 추후 서명 도입                                   |

## 8. 용어

- **규칙(Rule)**: 경로 패턴 + 설명 + 안전도 + 정리 가능 여부 묶음 (DATA_SPEC.md)
- **보호 경로(Protected path)**: 규칙과 무관하게 코드에 하드코딩된, 절대 삭제하지 않는 경로 (SAFETY.md)
- **정리 항목(Cleanup item)**: `cleanable: true`인 규칙 하나가 UI에서 선택 가능한 단위로 나타난 것
