# PRD 완료 조건 점검표 (10단계, 2026-11-02)

PRD.md의 모든 기능(F1~F7)과 비기능 요구사항의 **완료 조건**을 하나씩 점검한 결과입니다. 정직하게 적었으며, 증거가 없으면 통과로 표시하지 않았습니다.

**표시 기준**

- ✅ **통과** — 자동 테스트나 실측으로 확인함 (증거를 같이 적음)
- 🟡 **부분** — 일부만 확인했거나, 구현은 됐지만 실측/실사용 확인이 남음
- ❌ **미통과** — 구현하지 않았거나 조건을 만족하지 못함
- 👤 **사용자 확인 필요** — 개발 중에는 실제 PC에서 실행하지 않기로 한 것(삭제·제거·UAC)이라 사용자가 직접 확인해야 함

테스트 개수는 단위 테스트 430개 + 화면 테스트(E2E) 7개(+ 실제 C: 캐시가 있을 때만 도는 성능 점검 1개) 기준입니다. E2E와 삭제/제거 테스트는 모두 임시 폴더(가짜 드라이브)와 모의 제거 프로그램에서만 실행했고, 실제 파일 삭제나 실제 프로그램 제거는 한 번도 실행하지 않았습니다.

## 알려진 제한과 다음 할 일

1. **F7 포터블**이 이 PC에서 실행되지 않음(위 표). 설치 파일은 동작.
2. **클라우드 전용 파일(OneDrive)** 처리 미구현 — 필요하면 추가 단계로 제안.
3. **직접 확인이 필요한 것(👤)**: 실제 `C:\` 스캔 화면, 탐색기와 용량 비교, 설정 > 앱 목록 비교, 실제 정리(휴지통), UAC 정리, 실제 작은 프로그램 제거, 폴더 선택 대화상자.
4. 프로그램 화면의 표 맨 오른쪽 [제거] 열이 좁은 창에서 살짝 잘려 보일 수 있음 (기능에는 영향 없음).
5. 설정의 "디스크 점유 크기 기준" 스위치(UI_SPEC §7)는 만들지 않았다 — 스캔은 항상 디스크 점유 기준.
